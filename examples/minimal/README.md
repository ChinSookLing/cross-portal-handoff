# Minimal example

Not a real game. Not a record from Play. Nothing here authorises a submission.

Read these three files in order. Field names match [SPEC.md](../../SPEC.md). The historical games are in the other folders; start there only after this.

1. [handoff.txt](handoff.txt) — one complete handoff for a fictional activity, `EXAMPLE-001`, move 1.
2. [response.txt](response.txt) — the contestant's whole reply. The first line is the action. The rest is commentary and must not be parsed as a second action.
3. [recorded-result.json](recorded-result.json) — what the table stores if it accepts that reply. `raw_response` is the reply unchanged.

`session_id` in these files is an example seat name. It is not a secret.
